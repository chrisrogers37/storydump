### Fixed

- **A past-posts video can now post: storydump judges it only on what reaches Meta.** Meta never receives a video's source file. It fetches the transit store's story derivation, delivered as MP4 in the story frame, so `media_validation` no longer judges the source's edit lists, `moov` position, encoding settings, frame size, interlacing, GOP or audio settings. A video is supported when all of these hold: it is under the byte cap; it is a well-formed, self-contained MP4 or MOV; it has a video stream `ffprobe` can open (H.264 or HEVC, with AAC audio: the decoders the probe runs on untrusted bytes); it is 3 to 60 seconds long; and, where its file states a frame rate, it runs at 23 to 60 frames a second. A video that passed every check used to stay `validation_pending` (`needs_spec_evidence`), so no past-posts video could post, and the edit list an MP4 encoder writes by default refused many before that. The validator now reads only `ffprobe`'s JSON, so it no longer pins FFmpeg 7.1 or runs full decodes. The matrix version is `instagram-story-2026-10-25-v2`.
