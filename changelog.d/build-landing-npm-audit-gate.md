### Security

- **CI audits the landing site's runtime dependencies: a known advisory fails the Front End check (#681).** The Front End job now ends with `npm audit --omit=dev` in `landing/`. A known advisory against a runtime dependency, direct or transitive, fails the job, the way `pip-audit` already gates `requirements.txt`. The scope is a production install, so devDependencies are outside it: the build's Tailwind toolchain as well as the test and lint tooling. There is no severity floor: `npm audit` cannot suppress one advisory, so a floor would hide every advisory below it. An advisory is cleared with a bump or an `overrides` pin in `landing/package.json`. The step runs whether or not the lockfile changed, so a newly published advisory turns every pull request's Front End red until a bump lands. It runs last, so the tests, typecheck and lint still report meanwhile. The runtime dependencies have no known advisories today.
