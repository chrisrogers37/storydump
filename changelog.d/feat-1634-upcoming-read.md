### Added

- **A read for the calendar's upcoming days: a date range's planned stories and its predicted cadence slots (#1634).** `GET /api/v1/workspaces/{ws}/upcoming?from=&to=` answers for the workspace's local days `[from, to)`, at most 45 of them, behind the session and member check the other workspace reads use. `planned` holds the stories a person scheduled that are still scheduled, as the intents read returns them, each with its `day`. `predicted` holds the slots the cadence will open. No table holds those, because a cadence story is created only when its slot comes due, so the read projects them on the server with `fn_next_slot`, the function the clock advances each account's slot cursor with, under that account's own time zone, posts per day and posting hours, and the workspace's where the account sets none. A predicted slot says `kind: predicted` and carries no state. An account that is not active, and any account of a paused workspace, has none. Each list says when it was cut at its limit. No page reads it yet: the calendar's use of it is a later change.
