### Changed

- **The site's analytics move from Plausible to PostHog in cookieless mode, sending the same pageviews and the same seven events.** `landing/src/lib/posthog.ts` loads posthog-js's slim build from the site itself after the page hydrates, the first time something is sent, and sends to `https://us.i.posthog.com`, the only third-party origin the Content-Security-Policy now allows (`connect-src`; no third-party script source remains). Nothing is written to the visitor's browser. Every optional feature is off (autocapture, session replay, heatmaps, surveys, feature flags and remote config, exception and performance capture), no person profile is made, and every event passes `redact`: the page's address loses its query string, the three UTM tags become properties, the referrer is cut to its site, search terms and screen, timezone and language details are dropped, and an event from an invite page (`/join/…`, whose path is the invitation token) is dropped whole. `NEXT_PUBLIC_PLAUSIBLE_DOMAIN` is replaced by `NEXT_PUBLIC_POSTHOG_KEY`; unset, the site sends nothing. The PostHog project needs Cookieless server hash mode on, or PostHog drops every event.
