### Changed

- **The site's analytics move from Plausible to PostHog in cookieless mode, sending the same pageviews and the same seven events (#1598).** `landing/src/lib/posthog.ts` loads posthog-js's slim build (pinned at 1.436.1) from the site itself once the browser is idle after the first event, and sends to `https://us.i.posthog.com`, the only third-party origin the Content-Security-Policy now allows (`connect-src`; no third-party script source remains). Nothing is kept in the visitor's browser: persistence is in memory, and no debug flag can be stored from a link. Every optional feature is off (autocapture, session replay, heatmaps, surveys, feature flags and remote config), no person profile is made, and every event passes `redact`: the page's address loses its query string, the three UTM tags become properties, the referrer is cut to its site, page titles, search terms and screen, timezone and language details are dropped, and an invite page (`/join/…`, whose path is the invitation token) sends nothing and is never named as a previous page. An event keeps the page and time it happened on even when the library arrives later. `NEXT_PUBLIC_PLAUSIBLE_DOMAIN` is replaced by `NEXT_PUBLIC_POSTHOG_KEY`; unset, the site sends nothing. The PostHog project needs Cookieless server hash mode on, or PostHog drops every event.
