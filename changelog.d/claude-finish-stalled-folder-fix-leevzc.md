### Fixed

- **A Drive file the publish can never fetch no longer stalls its folder (migration 105, `07` §48; #1545).** A file deleted from Drive after it synced, or one past the publish's byte cap (8 MiB for an image, 40 MB for a video; phone videos often pass it), was redrawn by every slot for its folder until someone tapped Skip, and a skip lasts 45 days. The sync, where Drive's state enters, now records each file's size in `media_items.file_size` (054's column, which nothing wrote; the dashboard's media grid already shows it) and lands a file past the cap as `unsupported`, judged from the listing against the publish's own numbers: `PUBLISH_MAX_BYTES` moves from `src/worker.py` to `vocabulary.py`, so the worker and the sync read one spelling. A walk that saw the whole tree tombstones the source's rows it did not list, and that predate the walk, as `missing`: every row a walk lists is stamped `last_listed_at` (new, nullable; the stamp only moves forward, so a writer whose transaction opened earlier cannot move it back), and the walk's start, read from the database's clock, rides its cursor. A row landed while the walk ran is judged by the next walk instead, which keeps the device-native drop relay's rows safe. `missing` is the file's own absence, not the folder's retirement: a re-pick revives `removed` rows and leaves `missing` ones, and a walk that lists the file again revives it. Every way a walk skips part of the tree now rides its cursor (`partial`, beside the folder cap's `truncated`): a folder past `FOLDER_LIST_CAP`, a subfolder listing that repeats its page token, a folder that vanished before or during its listing. Only a walk whose adapter says it skipped nothing (`whole`, read by `drive_adapter.walk_saw_whole_tree`) tombstones anything, so an adapter or a lister that does not say so can never retire the library. The miss door (`fn_planned_misses`) names a planned story's missing file `item_missing`, the CLI and the notice say it in words, and a rename in Drive now reaches `file_name` on the next walk.
