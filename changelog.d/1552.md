### Added

- **A member can give an item the link its stories ask a person to add by hand (#1413, phase 7a).** Instagram takes no link sticker on a story published through the API, so the link is shown for a person to add when the story posts. The new command `set_item_link` (floor `member`, F11) sets or clears an item's link. It takes only an `https://` address of at most 2,048 characters (`LINK_URL_MAX`) with no space or control character in it, `null` clears it, and every change leaves an audit row naming the link set or cleared. The link is the item's, so every story of it asks for the same one. The CLI gains `storydump link <item> <https-url>` and `storydump link <item> --clear`, under a fresh key per run. No DDL: `media_items.link_url` already exists (054) and the runtime logins may write it (057). The approval card's link line is phase 7b, and the web's link field follows #1535.
