### Security

- **The Public record check finds an identifier that a hard wrap splits across lines.** It read one line at a time, so an identifier of several words wrapped between them, in a file, a commit message or a pull request's body, went unseen. Each text is now read again with its wraps joined, the next line's indent and comment or quote marker read as one space, and a match is reported on the line where it starts.
- **A push's commit messages are checked.** The push run read only the tracked files, so a commit message that landed without a checked pull request, from a fork, from Dependabot or pushed directly, was never read. The run now reads the commits the push brings: `before..after`, or the commits the event lists when the clone lacks `before`.
- **A list of only blank lines and comments no longer passes as a list.** Under `--require-list` a secret that holds no identifiers read as a clean pass; it now fails as a missing one does.
- **`scripts/lint.sh` reads the branch's commit messages since `origin/main`.** CI reads a pull request's, and its advice to run `lint.sh` now finds a hit in a commit message as well as in a file. A pull request's title and body are still checked against the list by hand.
