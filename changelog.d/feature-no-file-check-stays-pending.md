### Fixed

- **A past-posts video whose probe fails in words that say nothing about its bytes no longer stays pending (#52).** A decoder the probe keeps closed, or its own stream bound, let the file be judged without the probe, and words that establish malformed bytes refused it; any other fault left the file pending on every try, so it never posted and never got a reason. That fault is now the probe's, not the file's: the file is judged without the probe, since its story derivation re-encodes it, and its evidence records the probe's exit status (`probe_skipped`, `fault_exit_status`).
- **A check of a past post's file that cannot finish on our side is tried a bounded number of times (#52).** A missing tool, a host without resource limits, the validator's time or output budget, or a probe ended by a resource limit left the file pending, and the story's prepare job tried it again until the story's window closed, however many tries that took. Such a check now counts against the same tries as a refused fetch: it is tried again after the same doubling wait, and the last try (the eighth, by default) parks the story for review with the check's evidence. The file is not held back, so a later story tries it again.
