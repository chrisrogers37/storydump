### Fixed

- **A file two connected folders both list keeps one owner (#1645).** The sync takes over a live row by its Drive file id (#1628), so a file moved between connected folders keeps its row. That takeover now waits for evidence the file left its folder: another connected folder that lists the same file takes the row over only once a walk of the owning folder that saw the whole tree has missed it. That whole-walk evidence is the kind the two-walk tombstone reads, from each folder's cursor, so there is no schema change. One such miss is enough here, because the other folder's listing shows the file still exists. A file with two parents, or one under a folder connected inside another, no longer changes owner, category and path on every walk. A moved file still keeps its row, at the owning folder's next whole walk.
