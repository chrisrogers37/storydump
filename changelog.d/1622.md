### Added

- **An item can carry the link its stories ask a person to add by hand, set from the Media Library and shown in the Queue (#1413, phase 7).** A Media Library card shows its item's link and offers Link…, which saves one or removes it. The link's rule is the API's: an https:// address with a host, no spaces, no user name or password, and at most 2,048 characters; a refused link is answered with the whole rule. Every Queue row whose item has a link shows it. A link is clickable only when it is https with a host and no user name or password, and it opens in a new tab with no referrer; anything else is shown as text. An app cannot attach a link to a story it publishes, so the Queue offers no Approve for a linked story awaiting approval, leaving Posted myself, Skip and Reject; that is fork F10 (a)'s rule for the approval card's Post now. The API's media and queue reads now return `link_url`; the schema does not change.
