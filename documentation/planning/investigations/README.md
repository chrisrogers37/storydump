# Investigations — production incidents while they are open

One folder per production incident (`/investigate-app`): the record, `00_INVESTIGATION.md`, and
its fix plans. When an incident is resolved its folder moves to
[`../../archive/investigations/`](../../archive/investigations/) under the same name, as every
completed plan does ([`../README.md`](../README.md)). A folder here other than this file is an
open incident.
